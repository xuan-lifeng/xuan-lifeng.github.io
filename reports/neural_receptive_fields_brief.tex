\vspace*{4mm}
{\LARGE\bfseries\color{navy} Dynamic Receptive Fields\\[-1pt] in Mouse Auditory Cortex}\par
\vspace{3pt}
{\small Xuan Li Feng \quad\textbar\quad Imperial College London \quad\textbar\quad 2025--2026}\par
\vspace{10pt}
\begin{summarybox}
\textbf{Public technical summary.} This project tested whether a deep neural model could predict auditory-cortical activity from natural ultrasonic vocalisations and expose response structure that static receptive-field methods miss.
\end{summarybox}
\vspace{10pt}
\textbf{Research question}\par
\vspace{2pt}
Can a stimulus-dependent receptive field capture nonlinear neural-response behaviour that is not represented by static methods?
\vspace{11pt}

\textbf{Analysis workflow}\par\vspace{5pt}
\begin{center}

\begin{minipage}[t]{0.485\linewidth}
\textbf{Method}\par\vspace{3pt}
\begin{itemize}
\item Trained a five-layer causal Conv1D model in PyTorch on sound spectrograms from 46 mouse auditory-cortex units.
\item Used Jacobian-based automatic differentiation to derive dynamic spectrotemporal receptive fields from the trained network.
\item Benchmarked against spike-triggered average, spike-triggered covariance, and maximum-noise-entropy models.
\end{itemize}
\end{minipage}\hfill
\begin{minipage}[t]{0.485\linewidth}
\textbf{Evaluation}\par\vspace{3pt}
\begin{itemize}
\item Measured held-out prediction quality with Pearson correlation and noise ceilings.
\item Used shuffle tests and matched comparison protocols to assess whether performance differences were robust.
\item Examined temporal hold: persistence of a receptive-field pattern through time.
\end{itemize}
\end{minipage}
\vspace{10pt}

\vspace{10pt}

\textbf{Interpretation}\par\vspace{3pt}
Under matched settings, the dynamic model outperformed static alternatives. The analysis also showed that temporal resolution and evaluation choices can materially alter conclusions. The resulting workflow supports context-dependent receptive-field analysis for naturalistic neural stimulation.
